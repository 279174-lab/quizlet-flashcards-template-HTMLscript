# Flashcards

Simple template for creating interactive flashcards.  
Just edit the data array and instantly generate a full flashcard app.

## ✨ Features
- Flip cards
- Progress tracking
- Shuffle mode
- Hard cards filter
- MathJax support (LaTeX formulas)

## 🚀 How to use
1. Open `flashkarty.html`
2. Edit the `data` array
3. Add your own flashcards

## 🛠 Built with
- HTML
- CSS
- JavaScript (vanilla)
